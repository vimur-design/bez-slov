# Как мы понимаем без слов

Сайт по десктопному и мобильному макетам Figma. Десктоп: контейнер 1140 px по центру, фоны и крупный декор на всю ширину окна. Мобильная композиция 390 × 4160 px включается до 768 px и подстраивается под экран. Проверены ширины 375, 390, 430, 1440 и 1920 px.

Сайт: https://vimur-design.github.io/bez-slov/

HTML, CSS и JavaScript без зависимостей. Все иллюстрации, SVG и шрифты загружаются локально. Меню закреплено сверху и ведёт к разделам страницы; текст при наведении имеет opacity 70%.

Публикация: GitHub Pages, ветка main, корень репозитория.
